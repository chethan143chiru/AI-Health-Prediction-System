🏥 AI Health Prediction System

An AI-powered web application that predicts the risk of multiple diseases using Machine Learning and Explainable AI (XAI). The system provides health risk analysis, personalized recommendations, visual insights, and downloadable health reports through a secure and user-friendly interface.

---

📌 Overview

The AI Health Prediction System is designed to assist users in understanding potential health risks by analyzing medical information and lifestyle factors. It combines Machine Learning models with Explainable AI techniques to make predictions more transparent and understandable.

«Note: This system is intended for educational and research purposes and should not replace professional medical advice or diagnosis.»

⚙️ Installation

Clone the repository:

git clone https://github.com/yourusername/AI-Health-Prediction-System.git

Navigate to the project:

cd AI-Health-Prediction-System

Create a virtual environment:

python -m venv venv

Activate the environment:

Windows

venv\Scripts\activate

Linux / macOS

source venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open your browser:

http://127.0.0.1:5000
